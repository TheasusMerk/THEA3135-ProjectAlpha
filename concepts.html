CONCEPTS

  1. Programming, the process of presenting an electronic device, such as a computer, with a set of instructions, and for those instructions to be used to perform a certain task.

    Programs are developed by programmers (people who code programs) using a programming language like Java, JavaScript, C++, Python, etc.

    Each programming language has its own set of rules called the syntax which allows the electronic device to interpret written characters and execute commands. Without using the proper syntax, the intended command will not work and would usually generate an error.

    Citation:

    1. Code Academy: Programming
    2. Code Academy: Programming Terms
    3. Code Academy: What is Programming?

  2. Network, in technical terms, is the collection of servers, mainframes, computers, and other electronic devices, that are connected with each other, are able to communicate, share resources and exchange data with one another. Desktop computers, webcams, smartphones, routers, and the Internet are just some examples of network devices, all of which are connected with each other.

    Citation:

    1. Cisco
    2. Computer Hope: Network

  3. Though the true definition of a computer is a device that is capable of calculations, current computers are capable of substantially greater operations.

    Nowadays, there are a multitude of computer types available, but a computer is primarily defined as an electronic device that is capable of accepting data (Input), store and process that data, and output the sought-after information.

    Here are some types of computers that exist in the world today:

    Embedded computer: tiny computers embedded into products to perform specific functions or tasks for that product (example: blind spot detection sensor in cars, toy noise maker).

    Mainframe computer: powerful computers used to host a large amount of data and programs available to a wide group of users

    Mobile Device: mobile phones, small tablets, and other small personal devices that contain built-in computing or Internet capabilities (example: smartphones, media tablets)

    Supercomputer: extremely powerful computers used for complex computations and processing

    Citation:

    1. Computer Hope: Computer
    2. Morley, D. (2014). Understanding Computers in a Changing Society. [VitalSource Bookshelf].

  4. The protective shield put on data and computer hardware to stop unauthorized access and acquisition of data, normal or sensitive. A highly common security risk nowadays is the infection of your computer through a malicious software program, typically acquired through the installation of a program from a suspicious site. The aim of malware programs is to alter the manner of operations that a computer works off of. Implementation of firewalls, passwords, encryptions, and other computer security features can prevent unauthorized access of a device(s).

  5. Similar to a phone number, an IP address (Internet Protocol Address) is series of numbers that act as an identity for a device on a network. The unique numbers of IP addresses identify the sources and destinations of transmitted data (direct internet traffic to its intended destination).

    “There cannot be two computers on the internet using the exact IP address or exact same domain name.” (Textbook pg28)
