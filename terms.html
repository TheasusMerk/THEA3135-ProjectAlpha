TERMS

  1. Computer Literacy: The knowledge and understanding of basic computer fundamentals.
  2. Input: Process of entering data into a computer.
  3. Processing: Performing operations on data that has been input into a computer to convert that input into output.
  4. Output: Process of presenting the result of processing.
  5. Storage: The operation of saving data programs, or outputs for future use.
  6. Communication: The transmission of data from one device to another.
  7. Data: Raw, unorganized data.
  8. Information: Data that has been processed into a meaningful form.
  9. Hardwear: The physical parts of a computer system, such as the keyboard, monitor, printer, etc.
  10. Software: The instructions, also called a computer program, that are used to tell a computer what it should do.
  11. Operating System: The main component of system software that enables a computer to operate, manage its activities and the resources under its control, run appliations, program, and enterface with the user.
  12. Boot: To start up a computer.
  13. Windows Desktop: The background work area displayed on the screen for computers running Microsoft Windows.
  14. Application Software: Programs that enable users to perform specific tasks on a computer, such as writing letters or playing games; also called apps.
  15. Embedded Computers: A tiny computer embedded into a product and designed to perform specific tasks of functions for that product.
  16. Mobile Device: A very small device that has buit in computing or internet capabilities.
  17. Smartphone: A mobile device based on a mobile phone that includes Internet capabilities and can run mobile apps.
  18. Media Tablet A mobile device, usually larger that a smartphone, that is typically used to access the Internet and display multimedia content.
  19. Personal Computer: A type of computer based on a microprocessor and designed to be used by one person at a time.
  20. Desktop Computer: Personal computer designed to fit on or next to a desk.
